# U-Mich 2026-27 Academic Calendar (No-Class Days)

Download the events file and import it into your calendar.

## File
- `umich_2026-27_no_class_days.ics` — all "no class" days + exam windows for Fall 2026, Winter 2027, Spr/Sum 2027 (all-day events, .ics).

## Import into Google Calendar
1. Go to https://calendar.google.com
2. ⚙ Settings → Import & export → Choose File → select the .ics
3. Choose a calendar (e.g. create "U-Mich 2026-27") → click Import.

Source: U-Mich Registrar academic calendar, 2026-27.
